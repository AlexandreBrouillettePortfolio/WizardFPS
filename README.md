# WizardFPS
Made on Godot v.4.2.2

Currently in the prototyping phase, this is an FPS where the player controls a mage able to control five elements: the classic Lightning, Earth, Wind, Ice and Fire.

All assets are made by me, with the exception of the files currently in Placeholder Sprites and Sounds.

Link to showcase: https://youtu.be/zmMWghNoNko

Guide to File Tree:
- Test_Assets: Contains the assets made for the project, from textures to the shaders.
  - 360Sprites: The spritesheets used by the 2D projectiles which can be viewed from any angle.
  - CharacterSprites: The spritesheets used by NPC characters.
  - PlayerSprites: The hand sprites visible to the player.
- Test_Objects: Contains all non-scene .tscn files
- Test_Scenes: Contains the .tscn files which can be started as a playable scene.
- Test_Scripts: Contains all the .gd script files.
- Text_VFX: Contains all Visual Shader, Texture and Object files for visual effects.
